# Stage 05 Agent Core V1 工作包

- 日期：2026-09-10
- 状态：执行中
- Gate：Gate 05（本工作包通过不等于 Gate 05 正式通过）

## 目标

把当前可运行 Demo 中最影响真实阅读体验的断点收成一个纵向闭环：用户可直接聊天；划选正文只形成可取消的一次性上下文；服务端对自由文本优先使用低成本语义路由；书内问题经过受控上下文组装和证据门禁；真实模型增量直接通过 SSE 到达界面；界面立即显示用户消息、清空输入并允许停止；目录和 AI 面板可收缩，AI 面板可调宽，设置从对话区移出。

## 固定边界

- 保留单 Agent、轻量自研 Runtime、FastAPI＋React＋REST/SSE。
- 确定性 UI 动作和可信选区不调用意图模型；普通自由文本在模型可用时走结构化语义分类，失败时才走明确标记的降级路由。
- 选区不自动保存为划线；永久划线/笔记必须是独立显式动作。
- 选区原文是本轮首要书内证据，检索只补充上下文，不把选区文本拼进查询冒充理解。
- 本轮不接外部 MCP、不启用付费语音、不启动 Docker、不宣称 Repository/Worker/多端生产边界完成。

## 验收清单

1. “你叫什么名字”等闲聊不再默认进入书内检索；语义路由失败有可观测降级来源。
2. 临时选区可直接附加、移除和随本轮发送，且不创建永久 Highlight。
3. 提交后输入立即清空并出现用户气泡；状态依次可见为理解、检索、组织回答；失败时可恢复草稿。
4. 真实 Provider 使用 `stream=true`，SSE `answer_delta` 来自上游增量；测试替身仍兼容。
5. 生成可取消；终态为 completed、failed 或 cancelled，不能悬挂。
6. ContextPackage 有固定预算和裁剪诊断，选区与安全/证据边界不可被历史挤掉。
7. 目录和 AI 面板可收缩，AI 面板宽度可调并在浏览器保存；设置位于独立抽屉。
8. 相关后端测试、前端构建通过；集中修复后只做一次定向复验和一次有界审计。
