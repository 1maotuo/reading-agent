# Stage 05 意图识别 V3 最小工作包

- 日期：2026-09-11
- 状态：开发预览完成；Gate 05 不变
- 目标：在现有 V2 一次轻量语义路由上增加当前话题指代、有限认知判断和服务端回答策略。

## 冻结范围

V3 仍只调用一次轻量语义模型。模型返回现有意图轴，以及：

- `topic_source`：明确引用、上一轮、当前视图、歧义或未知；模型只能从服务端提供的话题候选中选择。
- `topic_confidence`：话题指向的候选把握程度。
- `cognition`：`mode`、`learning_goal`、`comprehension_state`、`friction_type`、可验证的用户原话短引文和认知把握程度。

服务端验证引文、锁定范围并生成白名单 `response_strategy`。闲聊不做学习状态判断；阅读器明确按钮走确定性路径；低证据认知降为未知，不写入长期记忆，不扩大工具权限。

## 指代与澄清规则

优先级为明确引用/回复对象、上一轮唯一话题、近期连续话题、当前阅读位置。唯一候选直接回答；只有候选冲突、没有候选或不同解释会明显改变结果时才澄清。中等把握时允许采用“如果你指的是……”的软确认。

## 非目标

不重做记忆系统、上下文预算、Agent Loop、工具权限、前端交互或数据库；不增加第二个模型调用；不更新 Gate 05。

## 最小验收

覆盖上一轮模糊追问、当前话题候选、无证据认知降级、闲聊隔离、真实歧义澄清、无模型降级和旧 V2 兼容。模块自测后只做受影响范围回归，不做独立审计循环。
