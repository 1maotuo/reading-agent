# F-03-01 真实书籍兼容性有界复验计划

- 日期：2026-09-09
- 目标：补充现有合成样本无法证明的真实书籍解析证据。
- 原则：预算与时间受限；只测两个合法公开领域样本，只执行一次；发现P0/P1时最多集中修复一次并定向复验。

## 冻结范围

1. EPUB：Jane Austen《Pride and Prejudice》，Project Gutenberg #1342。
2. 文字型PDF：A. N. Whitehead《An Introduction to Mathematics》，Project Gutenberg #41568。
3. 仅验证上传解析前置能力：格式识别、章节/段落结构、稳定ID、来源定位和抽样锚点恢复。
4. 不调用大模型，不把书籍正文写入治理账本，不验证OCR、双栏/复杂表格、生产对象存储或全部真实书籍兼容性。

## 通过门槛

- 两份文件均可解析，且至少产生1章、20个正文Block。
- 同一输入连续解析两次的结构化结果一致。
- 每份书抽取首部、中部、尾部等最多12个Block，来源锚点均可恢复到原文。
- 报告记录来源URL、文件SHA256、字节数、章节/节/Block数量、抽样结果和退出状态。
- 任何样本失败均保持失败，不以合成文件或手工结果替代。

## 停止条件

- 首次通过：记录证据后立即停止，不扩充书单。
- 首次失败：仅修复直接影响真实书籍主链路的P0/P1；P2登记待办。
- 需要OCR、绕过版权限制或大范围重写解析器时停止，不自动扩大范围。
