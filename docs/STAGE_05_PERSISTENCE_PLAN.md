# Stage 05：0.0.3 持久化预览工作包

## 目标

在不改变现有 API 和前端交互的前提下，让本地开发预览在服务重启后恢复书籍、版本、章节、Block、Chunk、阅读进度、划线、证据、问答历史和已完成任务。

## 边界

- 使用 Python 标准库 SQLite 作为本地开发适配器，不新增服务或第三方依赖。
- 上传原文件继续保存在 `var/dev-data/uploads`；SQLite 只保存恢复闭环所需的结构化状态。
- 只保存显式 JSON，并在恢复时重新经过 Pydantic 模型校验；禁止 `pickle`。
- 不持久化会话令牌、CSRF、API Key 或完整 Trace；服务重启后允许用户重新登录。
- 本工作包不代表 PostgreSQL、pgvector、真实多端同步、生产认证或 Gate 05 通过。

## 完成条件

1. 首次启动上传并完成阅读、进度更新、划线和问答。
2. 使用同一数据目录重新创建应用并重新登录后，上述业务状态可恢复且引用仍能回到原 Block。
3. 其他用户不能读取恢复后的私有书籍或证据。
4. 状态写入具备事务边界；损坏或不兼容状态必须安全拒绝，不能静默覆盖。
5. 原有 29 项回归与新增定向测试通过；只进行一次集中 P0/P1 修复和一次有界独立复核。
